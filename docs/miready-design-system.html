Design brief

Built from the mark, applied to the real app

The logo is a single unbroken yellow line coiling into a green field, bound in a thick black outline. Every token below is pulled straight from that. This pass maps those tokens onto MIReady's actual screens: question loading, answer submission, immediate feedback with explanations, next-question navigation, a score summary, and the AI prompt builder that generates the question bank itself.

01 — Color

Two brand colors, four supporting

Spiral Green and Loop Yellow carry the brand. Ink is the outline weight the logo is built on — used as a structural line, not just body text. Parchment keeps backgrounds warm instead of sterile white. Coral and Deep Moss exist only to answer the quiz app's real question: right or wrong.

06 — Prompt builder

Configuring the question source

Before questions ever reach the quiz card, they're generated: a form of runtime parameters assembles into a single AI prompt, previewed in mono so it reads like the payload it becomes.
